# 用途
讓 3D 主體產生立體感與層次的最基礎照明方法。



# 三點燈光
1. **主光（Key Light）**：最亮的光，放在主體前方側面，用來照亮主體並製造主要陰影。
2. **輔光（Fill Light）**：較弱的光，放在主光相對的一側，用來減弱陰影並顯示暗部細節。
3. **輪廓光（Rim / Back Light）** ：放在主體後方，用來勾勒主體的邊緣，將主體和背景分開。

# 可自由調整

## 1. 角度與距離的自由變化

- **寬打光（Broad Lighting）**：將主光照在面向攝影機較多的一側，角色看起來較飽滿、柔和。
- **窄打光（Short Lighting）**：將主光照在遠離攝影機的一側，臉部陰影變多，看起來更有戲劇張力或神祕感。
- **高低微調**：主光若從極高處往下打，會產生類似頂光的陰鬱感；輪廓光左右移動，能決定邊緣線條的粗細。

## 2. 光源的軟硬度（柔和度）

- **硬光（Hard Light）**：使用點光源（Omni）或聚光燈（Spot Light），會產生非常銳利、明顯的陰影邊緣。
- **軟光（Soft Light）**：在 Maya 中使用**區域光（Area Light）**並放大面積，會得到非常溫和、自然的漸層陰影。

## 3. 光比（Intensity Ratio）

- **高對比（High-Key）**：補光調得很強，幾乎沒有深色陰影。常用於喜劇、產品廣告或科技感場景。
- **低對比（Low-Key）**：補光非常微弱或完全關閉，只留下主光與輪廓光。常用於懸疑片、恐怖片或黑色電影（Film Noir）。

## 4. 色溫與色彩搭配

- **冷暖對比**：最經典的手法是主光用暖色（如溫暖的陽光），補光用冷色（如環境反射的藍天藍光），這能極大地增加畫面的色彩層次，而不會讓人覺得只是單純的「亮與暗」。
