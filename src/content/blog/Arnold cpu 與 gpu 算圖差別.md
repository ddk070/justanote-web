# Arnold 算圖
cpu 與 gpu 兩種可選。


# 算圖差別


## CPU
- 算圖速度慢
- 品質高
- 支援所有Arnold 算圖功能與進階節點
- 穩定性高


## GPU
- 算圖速度快
- 品質低
- 支援90%Arnold 算圖功能 ( 部分極複雜材質或特定第三方節點不支援 )
- 穩定性低

 > 適合用來快速測試打光與材質
