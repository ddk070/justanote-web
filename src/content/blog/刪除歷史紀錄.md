# 用途
1. 防止歷史紀錄過多引發檔案毀損與閃退
2. 縮小檔案容量提升系統效能
3. 交付乾淨檔案


# 刪除歷史紀錄

- **清理模型歷史紀錄：**`Edit > Delete by Type > History` (`Alt+Shift+D`)
- **不破壞骨架和權重：**`Edit > Delete by Type > Non-Deformer History`（非變形歷史）
- **清除沒在動的動畫死幀：**`Edit > Delete All by Type > Static Channels`
- **清除所有隱形垃圾、空群組與未使用的材質：**`File > Optimize Scene Size`
