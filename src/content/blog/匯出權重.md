# 匯出權重
方法有三種

## Export Deformer Weights
1. 選取塗好權重的模型
2. `Rigging 選單` >  `Skin` > `Export Deformer Weights` 旁的 Option Box (小方塊 ▢)
3. Export File： 點擊資料夾圖示，設定您要儲存的檔案路徑與名稱（檔名結尾為 .xml）
4. Skin Cluster： （Maya 2024 新增） 如果您的模型綁了多個 Skin Cluster，請在下拉選單中指定要匯出哪一層的權重
5. 點擊 **Export** 匯出

> 標準備份、相同模型之間的權重轉移。<br>
> XML文字檔。

## Paint Skin Weights
1. 選取模型
2. `Rigging 選單` > `Skin` > `Paint Skin Weights Tool ▢ `
3. 尋找`Export/Import Maps 區塊`點擊 `Export`
4. Size X / Size Y： 設定輸出的圖片解析度（例如 2048 x 2048）
5. Keep Aspect Ratio： 勾選保持長寬比
6. Image Format： 建議選擇 IFF 或 TIFF 等高位元深度的格式以確保精確度
7. 點擊 Export，Maya 會在您的專案資料夾中生成一個資料夾，裡面包含每根骨頭的黑白貼圖

> 模型拓撲點數不同、高低模對齊（需有相同 UV）。<br>
> IFF / TIFF黑白貼圖。

## [ngSkinTools](/blog/ngskintools/)v2 外掛
1. 開啟 ngSkinTools v2 的主要介面
 2. File > Export JSON
3. 選擇儲存路徑並命名

> 使用 ngSkinTools 製作時，需要保留圖層以便日後修改。<br>
> JSON文字檔，完整備份打包保留「權重圖層」、遮罩與非破壞性編輯數據。


# 匯入權重

## Import Deformer Weights
1. 選取模型
2. `Skin` > `Import Deformer Weights`
3. 在 Method（方法）中，如果兩個模型完全一樣，選擇 Index（依頂點編號）
4. 如果模型形狀相似但頂點編號不同，選擇 Barycentric（重心座標測量）


## Paint Skin Weights
1. 確認新模型綁定了與原本相同名稱的骨架
2. `Rigging 選單` > `Skin` > `Paint Skin Weights Tool ▢ `
 3. 尋找`Export/Import Maps 區塊`點擊 `Import`
 4. 點擊資料夾圖示，並點選裡面的任何一張 .iff 或 .tiff 貼圖（點一張即可，Maya 會自動依據骨頭名稱把整套貼圖讀進來）
 5. 如果新舊模型的 UV 完全一模一樣：選擇 U,V
 6. 如果模型形狀相似但沒有 UV 或 UV 變了：可以嘗試選擇 Over（依頂點最接近位置）
 7. 點擊 Import


## [ngSkinTools](/blog/ngskintools/)v2 外掛
1. 確認新模型綁定了與原本相同名稱的骨架
2. 選取新模型，在 ngSkinTools v2 面板中點擊 Initialize（初始化）
3. `File` > `Import JSON`
4. 如果兩個模型點序、拓撲完全一樣：選擇 Index（依頂點編號）
5. 如果模型形狀相同但點序被洗掉了：選擇 Position（依空間位置計算），它會自動比對最接近的頂點並把圖層完美貼過去
