# 用途
綁定物件與物件的[屬性](/blog/add-attribute/)數值跟隨動作

***

# set Driven Key
* `Animation ` 或 `Rigging ` 選單  ➔ `Key` ➔` Set Driven Key` ➔ Set... 開啟


## Driver（主控者）
- 左邊：主要控制的模型
- 右邊：Driver主要控制的屬性（x,y,z）
- 在面板（Channel Box）設定數值



## Driven（被控者）
- 左邊：跟隨的模型
- 右邊：Driven要跟隨動作的屬性（x,y,z）、設定數值
- 在面板（Channel Box）設定數值


## 底部按鈕
- **Key：** 將Driver與Driven設key（綁定）
- **Load Driver：** 匯入Driver（主控者）模型
- **Load Driven：** 匯入Driven（被控者）模型
- **Close：** 關閉Set Driven Key視窗
