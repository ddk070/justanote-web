# 用途
- 分配骨頭對模型影響的範圍
- 修正變形不自然、拉扯的範圍

***

# 權重
三種主要分配權重工具：
1. Paint Skin Weights Tool ：畫權重工具
2. Component Editor ：填權重數值工具
3. Hammer Skin Weights（Weight Hammer）：自動計算的權重修正工具


# Paint Skin Weights Tool
* `Animation` 或 `Rigging`選單    > `Skin` > `Paint Skin Weights Tool`設定方框
* `Ctrl` + `Shift` + 滑鼠右鍵長按 > 拖移至`Paint Skin Weights Tool`放開
* 點模型，滑鼠右鍵長按 > 拖移至左上角`Paint Skin Weights Tool`放開


## 繪畫重點
1. 權重值 0 ～ 1。（包含小數點）
2. `1` 代表**完全**受該關節控制（白色），`0` 代表**完全**不受影響（黑色）
3. 模型上的每一個頂點，都必須找到至少一根骨頭來跟隨
4. 使用平滑比刷讓模型彎曲時不僵硬

## 權重筆刷快捷鍵
- 按住 `B` + 滑鼠左鍵拖曳：調整筆刷大小
- 按住 `M` + 滑鼠左鍵拖曳：調整筆刷強度
- 按住 `Shift`：切換平滑（Smooth）模式

## 切換骨頭快捷鍵
1. 滑鼠左鍵兩下：切換至此骨頭
2. 按住 `Ctrl` + 點擊滑鼠左鍵：切換至此骨頭


# Component Editor
1. 選取模型的頂點（Vertex）
2. `Windows` > `General Editors` > `Component Editor`
3. 切換到 `Smooth Skins` 標籤頁，就能看到表格



# Hammer Skin Weights
1. 切換頂點模式，選取變形不自然附近的一個頂點
2. [擴大選取](/blog/model快捷鍵/#選取點線面)點範圍，直到選取到變形區域
3. ctrl取消正常區域的點
4. `Skin` > `Hammer Skin Weights`（按住` Shift` + `滑鼠右鍵` > `Hammer Skin Weights`  ）

- **擴大選取（Grow Selection）**：`Shift` + `>`


***

# Skin
- 其他內建的權重輔助工具
`Animation` 或 `Rigging`選單    > `Skin`

## Mirror Skin Weights（權重鏡像）
`Skin` > `Edit Smooth Skin `> `Mirror Skin Weights`

## Copy Skin Weights（複製皮膚權重）
 `Skin` >  `Copy Skin Weights`
