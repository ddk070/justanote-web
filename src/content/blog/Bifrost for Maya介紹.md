# 用途
maya內建的特效生成工具，流體、氣體、顆粒模擬、程式生成。


***


# Bifrost MPM（物質點法解算）
- 算雪、泥土、沙子、布料撕裂的多物理碰撞系統
- 雪球砸在地上碎開、泥濘黏稠感，不同材質互相影響時很強
- 運算極重、預覽不易；若只要單純的水流或煙霧，用傳統粒子或找 Houdini 更快
​
「黏稠物體混合」、「積雪崩落」
​


# Bifrost Strand（毛髮/線條生成）
- 用程式邏輯在模型上種線條
-  大量藤蔓生長、幾何紋理羽毛、程序化羽絨
- 做寫實長髮或複雜造型梳理不如 XGen 或專用毛髮外掛直覺
​
「藤蔓植物自動爬滿建築」、「非自然規則的線條生長」



# Bifrost Aero（煙霧與燃燒氣態解算）
- 算空氣流動、煙霧擴散、火焰爆炸的體積流體系統
- 煙霧遇到障礙物的渦流捲動、小規模燃燒或慢速消散效果
- 大規模爆炸或超寫實煙火的微調門檻高；業界這類鏡頭通常直接丟 Houdini，或直接套現成的 EmberGen 快取
​
「香爐裊裊細煙」、「火把冒煙」、「小規模氣流碰撞」



# ​Bifrost Liquid / BOSS（海洋與大型水體）
- 算水面波浪漣漪（BOSS）以及流體潑濺（FLIP 解算）
- 遠景海洋海浪生成、船隻破浪的泡沫貼圖、杯中液體晃動
- 網格重建（Meshing）與白水粒子快取極吃硬碟與記憶體，除錯週期長

「海面波紋背景」、「水杯潑水」、「岸邊碎浪」



# ​Bifrost Rigging & Deformation（節點式骨架變形，較新架構）
-  把原本寫在 DG 節點或 Maya 腳本裡的骨架約束與變形計算，搬進 Bifrost 引擎跑
- 運算速度極快、支援多執行緒並行運算，適合自製高性能的自定義變形器（如特定肌肉擠壓、二次擺動）
- 開發門檻高，且如果只是要做常規角色綁定，Maya 原生工具或 AdvancedSkeleton 已經夠快夠用，不需要重新造輪子

「大量角色同屏效能卡死」、「需要自製特殊碰撞變形器」



# ​Bifrost USD 生態銜接
- 透過視覺化節點直接讀取、編輯與輸出 Universal Scene Description（USD）場景階層
-  在不載入超大模型幾何的情況下，程序化組裝整座城市或森林的資產引用
- 需要懂整個工業級 Pipeline 的 Stage/Prim 概念，獨立個人短片或常規小專案派不上用場
​
「跨軟體超大型場景分件」、「大型影視/遊戲流水線交接」
