# 用途
將3D轉成2D，好讓未來材質好畫。<br>
若UV拆的好，可以避免上材質後，模型材質變形。


# 拆UV
1. 選取模型
2. Planar
3. 可以將物件上不知到哪裡出現的切線全部重製
4. 開啟UV Editor介面(`Windows > UV Editor`)
5. 確認物件是否正確出現在 UV 視窗中
6. 對物件選線切線 (CUT)，可以在3D視角或在UV Editor介面切線
7. 如果想縫合線可以用sew
8. 在UV Editor介面將物件全部框選
9. Unfold 攤平物件(Unfold)
10. 開黑白方格(檢查圖片)
11. 在UV Editor介面選起所有物件
12. Layout 自動排版UV物件(Arrange and Layout)
13. 右鍵選取UV Shell模式，手動調整位置

> 用線模式切，只是覺得快且方便。
> 如果想用面模式切，也可以。
> 依照個人習慣，使用即可。
