# 用途
- 列出所有不同物件的關鍵幀，並細分出XYZ軸的關鍵幀
- 想同時查看所有物件的關鍵幀並調整
- 例如：錯key、ik與fk對齊、聲音同步、複製貼上動作、批次刪除特定key

> maya2025更新了Dope Sheet界面，偏向現代剪輯軟體。

***

# Dope Sheet（攝影表）
有兩種方法：
- `Windows `>` Animation Editors` > `Dope Sheet`
- `Panels `> `Panel` >` Dope Sheet`


## 視窗操作
* **平移、垂直移動：**`alt` + `中鍵`
* **縮放：**`alt `+ `右鍵`
* **特定區域放大：**`ctrl `+ `alt `+ `左鍵`
* **特定區域縮小：**`ctrl `+ `alt `+ `中鍵`



## 移動key
- **移動：**`W`+`中鍵`拖移
- **縮放：**`R`+`左鍵`拖移



## 工具列

- **選取關鍵幀工具![选择关键帧工具Select Keyframe Tool](../../assets/Select-Keyframe-Tool.png) ：**  `左鍵`選取範圍
- **移動最近拾取的關鍵幀工具 (Move Nearest Picked Key Tool)：**
- **插入關鍵幀工具 ：** 新增關鍵幀
- **框顯全部(Frame all) ：** 顯示所有關鍵幀
- **框顯撥放範圍(Frame playback range)：** 顯示當前撥放範圍的關鍵幀
- **以目前時間的視角為中心(Center the view about the current time) ：** 以目前Time Slider所在的關鍵幀為中心
- **以下層級/無(Hierarchy below/none)：** 顯示子節點的關鍵幀，不管父節點是否有關鍵幀
- **自動加載選定对象(Auto Load Selected Objects)：** 開啟後只顯示選擇的物件
- **曲線編輯器（Graph Editor)：** 開啟Graph Editor
- **Trax編輯器 (Trax Editor)：** 開啟Trax Editor
