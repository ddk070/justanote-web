# maya 腳本語言


## MEL
- Maya 原生內建的腳本語言，適合快速執行簡單指令與修改介面。


## Python
 - 功能更強大、適合複雜運算與標準程式開發，並支援 PyMel（提供物件導向的 Maya API 封裝）。
 - 可讀取maya以外的資料或功能
 - 擁有世界上最龐大的生態系
 - 可用文字編輯器（VS Code）偵測語法除錯

> 「看懂 MEL 即可，但寫新工具請一律用 Python。」
