# 列表功能切換
**F1**：開啟 Maya 官方說明文件（Help）<br>
**F2**：切換至 建模 (Modeling) 選單集<br>
**F3**：切換至 變形 (Rigging) 選單集<br>
**F4**：切換至 動畫 (Animation) 選單集<br>
**F5**：切換至 FX / 特效 (Effects) 選單集<br>
**F6**：切換至 彩現 (Rendering) 選單集<br>
**F7**：切換至 自訂 (Custom) 選單集（若有設定）



# 視角控制 

* **視角旋轉 (Tumble)：** 按住 `Alt` + **滑鼠左鍵** 拖曳
* **視角平移 (Track)：** 按住 `Alt` + **滑鼠中鍵**（滾輪壓下）拖曳
* **視角縮放 (Dolly)：** 按住 `Alt` + **滑鼠右鍵** 拖曳（或直接滾動滑鼠滾輪）
* **框選聚焦 (Frame Selection)：** 選取物件後按 **`F` 鍵**（視角會自動對焦到該物件）
* **全景聚焦 (Frame All)：** 按 **`A` **（視角對焦場景內所有物件）

# 工具列快捷鍵
* **`Q`**：選取工具 (Select Tool)
* **`W`**：移動工具 (Move Tool)
* **`E`**：旋轉工具 (Rotate Tool)
* **`R`**：縮放工具 (Scale Tool)
* **`Y`**：使用上一個用過的非變形工具

<hr>

#  視窗切換 
* **單一/四視格切換：** 游標移到視口中，**輕點一下 `Space` (空白鍵)**。<br>
    *注：四視口分別為 Top (頂視圖)、Front (前視圖)、Side (側視圖)、Persp (透視圖)。*
* **Space（單按空格鍵）**：在單一視窗與四格視圖（Top、Front、Side、Persp）之間快速切換。
* **Shift + M**：隱藏或顯示目前視窗的頂部選單欄（Menu Bar）。
* **Ctrl + m**：隱藏或顯示 Maya 最上方的全域主選單欄（Main Menu）。
* * **`Ctrl + A`** ：開啟屬性編輯器

## Hotbox（彈出式全功能選單）

**長按空白鍵**：Hotbox
- 點擊**正中心**：快速切換視角（透視圖、上視圖、前視圖、側視圖）。
- 點擊**上方**：切換不同的視窗配置（如 Hypergraph、Outliner）。
- 點擊**下方**：切換顯示或隱藏 UI 元件（如時間軸、工具箱）。
- 點擊**左方**：切換選取遮罩（Masks）模式。


<hr>

# 視窗顯示模式 

* **`1`**：低品質顯示（粗糙/fast 顯示，適合大量物件時加速）
* **`2`**：中等品質顯示（一般場景常用）
* **`3`**：高品質顯示（平滑、精細，適合最終檢視）
* **`4`**：線框模式 (Wireframe)
* **`5`**：著色模式 (Shaded)
* **`6`**：紋理模式 (Textured)
* **`7`**：燈光模式 (Lit)
* **`8`**：真實渲染模式 (Rendered)


<hr>

# 物件選取與層級
* **`F8`**：切換「物件模式 (Object Mode)」與「組件模式 (Component Mode)」
* **滑鼠右鍵 (長按)**：在物件上長按，可彈出快捷選單切換 **Vertex (頂點)**、**Edge (邊)**、**Face (面)**。
* **`Ctrl + G`**：將選取的物件打組 (Group)
* **`P`**：建立父子關係 (Parent)
* **`Shift + P`**：取消父子關係 (Unparent)



<hr>


# 復原與重複
- **`Z` 或 `Ctrl + Z`**：復原 (Undo)
- **`Shift + Z`**：取消復原 (Redo)
- **`G`**：重複上一次的操作 (Repeat Last Command)
