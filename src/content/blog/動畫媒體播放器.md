# 簡介
- 用於動畫檢視（逐格播放）


# [Keyframe Pro](https://zurbrigg.com/keyframe-pro#downloads)
* 可免費下載
* 更多功能須付費解鎖
* 新出[Keyframe Pro 2](https://zurbrigg.com/keyframe-pro-2#downloads)可使用


# [QuickTime](https://support.apple.com/zh-tw/106375)
* 可免費下載
* 支援Playblast 輸出 H.264

> Apple 已停止支援 Windows 版 QuickTime 7。<br>
> 因為安全問題，maya也不再支援。
> 可用[DuBlast](/blog/DuBlast/)支援Playblast 輸出 H.264
