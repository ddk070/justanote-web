# 注意命名方式

 > 資料夾和檔案名不能包含 $, #, .，也禁止使用空格與中文；能有數字，但數字不能放開頭

***

# set project 用途
1. 管理與檔案相關的所有資料文件
2. 建立所有檔案的相對路徑
3. 確保團隊所有人的檔案、動態、材質路徑完全一致
4. 保持檔案結構整潔

***

# 設定專案

> 已建立專案資料夾，但剛進入maya，要開啟舊專案資歷夾

1. 點擊頂部選單的 **File**
2. 選擇 **Set Project...**
3. 瀏覽並選取您的專案主資料夾
4. 點擊 **Set** 按鈕確認

**workspace.mel負責紀錄所有檔案路徑，包括外掛與特殊快取路徑。**<br>
**若交付專案資料夾，檔案必須包含workspace.mel。**

***

# 建立新專案

> 尚未建立專案資料夾，要直接使用官方的預設專案結構

## set project
1. 點擊 **File** > **Project Window**
2. 點擊 **New** 並輸入專案名稱
3. 設定專案在電腦中的儲存路徑
4. 點擊 **Accept**，Maya 就會自動建立完整的工作資料夾（如 scenes、sourceimages 等）




### set project 資料夾結構
- **scenes：** 存放你的 Maya 專案檔（.ma / .mb）
- **sourceimages：** 存放你外面丟進來的素材與材質貼圖（.jpg / .png / .exr）
- **images：**  存放你 算圖（Render）出來的最終圖片或序列幀
- **autosave：** 存放自動備份的檔案（若有開啟自動儲存功能）
- **cache：**   存放毛髮、衣服、流體等動力學的緩存檔案（Cache）


## 自行定義資料夾結構

> 尚未建立專案資料夾，想自行定義資料夾結構


### 使用set project改
1. 點擊 **File** > **Project Window**
2. 點擊 **New** 
3.  **Project Name** 輸入你的專案名稱
4.  **Location** 選擇儲存路徑。
5. 下方的 **Primary Project Locations** 就是地圖。直接修改右側欄位（將欄位名稱改成你想要的自訂資料夾名稱）。
    1. _例如：把 `scene` 後方的 `scenes` 改成 `Maya_File_01`。_
    2. _例如：把 `sourceImages` 後方的 `sourceimages` 改成 `Textures_02`。_
6. 點擊 **Accept**。


### 編輯 workspace.mel
1. 對workspace.mel，按右鍵選擇 **開啟檔案 > 記事本（Notepad）**
2. 修改程式碼後儲存退出
3. 回到 Maya，重新執行 **File > Set Project**，選取這個資料夾

**【原本的官方預設】**
``` 
workspace -fr "scene" "scenes";
workspace -fr "sourceImages" "sourceimages";
workspace -fr "images" "images";

```

**【修改成你自訂的資料夾名】**
```
workspace -fr "scene" "Maya_File_01";
workspace -fr "sourceImages" "Textures_02";
workspace -fr "images" "Render_03";

```

**程式碼解釋：**
- workspace ： 告訴 Maya 我們現在要對「專案工作區（Workspace）」進行設定。
- -fr ：**參數（Flag）**，指定某種『檔案規則』 。
- "引號內容" ： **第一個引號**Maya 的系統功能代碼（不可更改）；**第二個引號**在硬碟中的資料夾名稱（可自由更改）。

> 若未來檔案連結失效可以檢查workspace.mel程式碼裡的資料夾使否有對應或註冊在裡面

### Maya 所有系統功能代碼
1. 點擊 Maya 介面右下角的 **Script Editor 按鈕**（外觀像是一個小對話框帶有半圓形箭頭的圖示），或者到頂部選單選擇 **Windows > General Editors > Script Editor**
2. 在打開的視窗中，確認切換到 **MEL 分頁**（預設通常會有一個 MEL 和一個 Python 分頁）
3. 將下方這行程式碼複製並貼進 MEL 分頁的輸入區：
```
workspace -query -fileRuleList;
```
4. 按下鍵盤小鍵盤的 **Enter**，或者點擊頂部工具列的 **雙綠色三角形按鈕（Execute）** 執行
5. 上方白色的歷史訊息視窗就會**完整列出您當前 Maya 版本所支援的所有系統功能代碼**
